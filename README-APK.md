# আমার বাংলাদেশ — Android APK প্রকল্প

এই ফোল্ডারটা GitHub-এ একটা **নতুন রিপোজিটরিতে** তুললেই GitHub নিজে APK বানিয়ে দেবে।
কম্পিউটারে Android Studio বা কিছু ইনস্টল করতে হবে না।

## ধাপ (একবারের কাজ)
1. GitHub-এ নতুন রিপোজিটরি খুলুন, নাম: `amar-bangladesh-apk` (Public বা Private, যেকোনোটা)।
2. এই জিপের ভেতরের **সব ফাইল-ফোল্ডার** (লুকানো `.github` ফোল্ডারসহ) ওই রিপোজিটরিতে আপলোড করুন।
   - `.github/workflows/build-apk.yml` ফাইলটি অবশ্যই যেতে হবে।
   - কম্পিউটারে লুকানো ফোল্ডার না দেখা গেলে হিডেন-ফাইল দেখার অপশন চালু করুন, অথবা GitHub Desktop ব্যবহার করুন।
3. রিপোজিটরির **Actions** ট্যাবে যান → "APK তৈরি করুন" → **Run workflow**।
   (Actions বন্ধ থাকলে "I understand… enable" চাপুন।)
4. ৫–১০ মিনিট পর কাজ শেষ হলে (সবুজ টিক) ওই রানে ঢুকে নিচে **Artifacts → amar-bangladesh-apk** নামান।
5. জিপ খুললে `app-debug.apk` পাবেন। ফোনে পাঠিয়ে ইনস্টল করুন
   (ফোন "অজানা উৎস থেকে ইনস্টল" চাইলে অনুমতি দিন)।

## অ্যাপ আপডেট হলে
Actions → Run workflow আবার চালান। এটা প্রতিবার আপনার সর্বশেষ অ্যাপ (GitHub Pages থেকে) নামিয়ে নতুন APK বানায়।

## ফোনে প্রথমবার
- নোটিফিকেশন ও **"অ্যালার্ম ও রিমাইন্ডার"** অনুমতি দিন।
- ফোন সেটিংসে এই অ্যাপের ব্যাটারি → "Unrestricted/সীমাহীন" করুন।
- অ্যালার্ম পাতায় "✅ APK মোড" লেখা দেখালে অ্যালার্ম ফোনের সিস্টেমে জমা হচ্ছে — অ্যাপ বন্ধ থাকলেও বাজবে।

## জানা সীমা
- বার্তার নোটিফিকেশন (অ্যাপ বন্ধ থাকলে) এখনো আসবে না — এর জন্য Firebase পুশ লাগে (পরের ধাপ)।
- APK-র ভেতরের ডেটা ব্রাউজারের ডেটা থেকে আলাদা; নতুন করে লগইন করতে হবে।
- এটি ডিবাগ APK (নিজের ও বন্ধুদের ফোনের জন্য ঠিক আছে)। Play Store-এ দিতে হলে রিলিজ সাইনিং কী লাগবে।
